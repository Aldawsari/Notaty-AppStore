# Notaty Privacy Policy

Last updated: June 9, 2026

Published URL: https://lab.aldawsari.com/AppleAppStore/notaty/privacy/

Notaty is a macOS menu bar notes app developed by Abdullah Aldawsari.

## Data collection

Notaty does not collect personal data.

Notaty does not:

- create user accounts
- send analytics
- include ad tracking
- upload notes to a server
- use third-party crash reporting SDKs

## Local storage

Notes created in Notaty are stored locally on the user's Mac.

If the user exports notes, the exported files are written only to the location the user selects.

## Screen capture and OCR

If the user chooses the OCR feature, Notaty requests macOS Screen Recording permission so the user can capture a selected region of the screen.

Captured content is processed on device using Apple system frameworks. Notaty does not transmit captured images or recognized text to an external server.
