## What's new

- **Attachments on text notes.** Drop files onto a note, the menu bar icon, or paste them with ⌘V. Attached files appear as chips beneath the title — click for Quick Look, drag between tabs to move, or back to Finder to copy out. Survives launches and is included in zip export/import.
- **Voice notes redesigned.** Each in-app recording now lives as a player card with inline waveform, drag-to-seek, play/pause, transcribe toggle, copy-to-note (✏️), and delete (×). Voice notes have their own strip above the file-attachment strip. Auto-transcribe is available as a Settings toggle (Voice Notes section, default off). Old voice notes migrate automatically.
- **Each voice note is named** "Voice Note 1", "Voice Note 2", etc. The transcript bubble and the inserted text block both reference the voice note's name so you can tell transcripts apart.
- **OCR reads QR codes.** When you capture a region of the screen for OCR, any QR codes in it are decoded alongside the recognized text — both interleaved by their visual position in the image. Useful for "scan to continue" QRs shown in the browser.
- **Pin window.** Keep Notaty open while you work — toggle "Keep window on top" in Settings → Window. When pinned, outside clicks no longer dismiss the window. Optional pin button in the tab bar.
- **"Check for Updates…"** added to the right-click menu on the menu bar icon.
